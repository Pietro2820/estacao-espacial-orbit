## Descrição das Camadas do Ambiente
Este repositório segue o fluxo de desenvolvimento corporativo para garantir a qualidade e a estabilidade do software em produção:

- **`develop`**: Ambiente de desenvolvimento contínuo. Onde as novas features são integradas.
- **`stage`**: Ambiente de homologação/testes. Onde o código é validado e testado antes de ir para produção.
- **`main`**: Ambiente de produção. Contém o código estável, testado e liberado para os usuários finais.
